Purpose:
The purpose of the fullstack-pdf-app is to allow users to upload PDF files, extract text from them, and ask questions about the content using OpenAI's language model.

Tech stack:
The tech stack includes Python 3.8+, Node.js 14+, npm or yarn, OpenAI API, FastAPI, PyMuPDF (fitz), React, Tailwind CSS, and Fetch API.

Architecture:
The application architecture consists of a backend built with FastAPI and a frontend built with React. The backend uses PyMuPDF to extract text from PDFs and OpenAI to interact with OpenAI's language models. The frontend uses Tailwind CSS for styling and Fetch API to make HTTP requests to the backend.
